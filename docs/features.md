# App Features

This document lists all features included in the Weather App.

## 1. Real-Time Weather Search
- Search any city worldwide
- View current temperature, conditions, and date
- Supports Enter key or Search button

## 2. 5-Day Forecast
- Midday temperature and weather
- Compact grid layout
- Midday (12:00:00) forecast for next 5 days
- Displays temperature + condition for each day

## 3. CRUD: Saved Cities
- Save your favorite cities
- Revisit saved cities anytime
- Delete saved entries
- Data stored in localStorage


## 4. Responsive Design
- Mobile-friendly UI
- Works on all screen sizes
- Smooth scroll and transitions

## 5. Loading & Error Handling
- Shows loaders during API calls
-- shows "Coming Up..." while data is fetched
- Handles empty input and 404 errors gracefully

## 6. React Router Navigation
- Built with React Router
- Pages: Home, Weather, About
- Scroll-to-top behavior included between pages
