# Component Reference

Documentation for all essential components in the Weather App.

## 1. Navbar.jsx
- Displays navigation links
- Includes dark mode toggle
- Uses React Router `<Link>`


## 2. Footer.jsx
- Contains footer links
- Supports scroll-to-top anchors
- Uses React Router `<Link>`



## 3. Weather.js
Core logic of the app:
- Handles search  
- Fetches weather + forecast  
- Manages loading + error states  
- Displays current weather  
- Displays 5-day forecast  
- Allows saving cities  


## 4. Forecast.js
- Receives `forecast[]` as props  
- Renders daily forecast tiles  


## 5. SavedCities.js
- Receives `savedCities[]`  
- Renders list  
- Handles delete actions
