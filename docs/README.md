# 🌦️ Your Daily Weather App Documentation

Welcome to the official documentation for the Weather App — a modern, responsive React application that displays real-time weather information and a 5-day forecast for any city.

This project demonstrates:
✔ API integration  
✔ State management  
✔ React Router  
✔ CRUD functionality  
✔ LocalStorage persistence  
✔ Responsive UI  

Use the sidebar files to explore installation instructions, API usage, architecture, and more.

##  Documentation Structure
- **api-reference.md** – API endpoints and data formats 
- **architecture.md** – App structure, folder diagram, technical workflow  
- **components.md** – Explanation of every major component
- **features.md** – Full list of app features  
- **setup-guide.md** – Installation, environment setup, running the project  
- **troubleshooting.md**- common problems and their solutions.

For questions or contributions, contact the project maintainer.
